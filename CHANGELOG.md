Notable changes are recorded here. Version numbers follow [Semantic Versioning](https://semver.org/).

## Unreleased

## 0.1.0 - 2026-08-19

- Added interactive Jellyfin login and private local credential storage
- Added a Bubble Tea TUI that starts when no subcommand is supplied
- Added library browsing, Continue Watching, Next Up, and Recently Added views
- Added search across episodes, series, movies, and other works
- Added `mpv` playback with Direct Play, Direct Stream, and Transcode selection
- Added playback progress, stop, completion, and resume synchronization with Jellyfin
- Added Linux, macOS, and Windows release builds with checksums
