# トラブルシューティング

[English](troubleshooting.md)

## ログインの期限切れ、または認証エラーになる

`jellycli login`を再実行してください。古いトークンが漏洩した可能性がある場合は、先にJellyfinの管理画面から無効化します。

## サーバーへ接続できない

設定したURLに`http://`または`https://`が含まれ、同じマシンから到達できることを確認してください。リバースプロキシ、TLS証明書、ファイアウォール、VPNの設定も確認します。TLS検証を無効化するのではなく、証明書チェーンを修正してください。

## 再生が始まらない

`mpv`がインストールされ、実行できることを確認します。

```sh
mpv --version
```

選択したアイテムを別のJellyfinクライアントで再生できることも確認してください。Jellyfinサーバーのログから、トランスコードツールの不足、権限問題、未対応コーデックなどを確認できます。

## 再生できるが進捗が同期されない

同じ再生セッションを複数の`jellycli`プロセスが操作していないことを確認してください。ローカルIPCエンドポイントを作成でき、その親ディレクトリへ書き込めることも確認します。プロセスを強制終了すると最後の停止通知を送れない場合がありますが、定期的な進捗通知により直近の位置は保存されます。

## Windowsで再生できない

Windows向けバイナリは配布していますが、`mpv`の名前付きパイプIPCが未実装のため、現在は再生に対応していません。閲覧など、再生を伴わないコマンドは動作する可能性があります。

## ローカル認証情報をリセットする

各OSのXDG互換設定ディレクトリにある`jellycli`の設定を探し、認証情報ファイルを削除してから`jellycli login`を実行してください。インストールしているバージョンで設定が同じファイルに保存されている場合は、機密情報を含まない設定を先にバックアップしてください。

診断情報を共有するときは、アクセストークンや非公開サーバーの情報を含めないでください。
